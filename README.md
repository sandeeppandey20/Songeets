# Songeets 🎵

Songeets is a music player web application built using HTML, CSS, and JavaScript, featuring a cozy green aesthetic and an interactive music-listening experience.

## Features
- Play and pause songs
- Next and previous song controls
- Interactive seekbar for navigating tracks
- Current playback time and song duration
- Song-specific play/pause indicators
- Animated GIF and currently playing song information

## Tech Stack
- HTML5
- CSS3
- JavaScript
- Font Awesome

## Run Locally
1. Clone this repository.
2. Open the project folder in VS Code.
3. Run `index.html` using the Live Server extension.
